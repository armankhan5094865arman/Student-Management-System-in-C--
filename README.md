## Student Management System in C++

A professional console-based Student Management System built with C++ for managing student records efficiently. This project demonstrates practical Object-Oriented Programming (OOP), STL, file handling, searching, updating, deleting, sorting, validation, and grade calculation.

## Features

Add Student — Store student ID, name, and marks.

Display All Students — Show records in a formatted table.

Search Student — Find a student using their unique ID.

Update Student — Modify a student's name and marks.

Delete Student — Remove a student record by ID.

Automatic Grade Calculation — A+ (80–100), A (70–79), B (60–69), C (50–59), D (40–49), F (below 40).

Sort by Marks — Arrange students from highest to lowest marks.

Duplicate ID Prevention — Prevents duplicate student IDs.

Marks Validation — Allows marks only from 0 to 100.

File Handling — Automatically saves records to students.txt.

Data Persistence — Loads previously saved records when the program starts.

Menu-Driven Interface — Simple and user-friendly console navigation.

## Technologies & Concepts

C++ • OOP • Classes & Objects • Encapsulation • Constructors • STL vector • File Handling (ifstream, ofstream) • sort() • remove_if() • Lambda Expressions • Input Validation • Searching • Sorting • iomanip Formatting
